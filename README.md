# Quiz Management System 📝

A beginner-friendly **Quiz Management System written in C** that allows users to take multiple-choice quizzes based on **category and difficulty level**, validates user input, calculates scores and percentages, assigns grades, reviews answers, and maintains high scores using file handling.

## ✨ Features

| Feature | Description |
| :--- | :--- |
| **Multiple-choice quiz questions** | Interactive MCQ format with 4 options each |
| **3 Categories** | C Basics, Operators, Loops |
| **3 Difficulty Levels** | Easy, Medium, Hard |
| **Input Validation** | Validates category, difficulty, question count, and answers |
| **Automatic Scoring** | Score, percentage, and grade calculation |
| **Grade System** | A++ to F grading scale |
| **Answer Review** | See correct vs. incorrect answers after each quiz |
| **High-Score Tracking** | Separate high scores per category + difficulty combination |
| **Replay Option** | Retake quizzes or start new ones |

## 📚 How the Quiz Works

### 1. Select Number of Questions
The user chooses how many questions to attempt (up to 6 questions per quiz).

### 2. Select Category
Choose from available categories:

1. **C Basics** 🎯
2. **Operators** ➕
3. **Loops** 🔄

### 3. Select Difficulty
Choose a difficulty level:

1. **Easy** 🟢
2. **Medium** 🟡
3. **Hard** 🔴

### 4. Answer Questions
Each question has four options (1-4). Invalid input is rejected and the user is prompted again.

### 5. View Results
After completing the quiz, see:

- Total score 📊
- Percentage score 📈
- Grade letter 🅰️🅱️🅲️
- High score 🏆

### 6. Review Answers
View your answers alongside correct answers to identify mistakes.

## 📊 Grading System

| Percentage | Grade |
| :---: | :---: |
| 95% – 100% | **A++** 🌟 |
| 90% – 94% | **A** |
| 80% – 89% | **B** |
| 70% – 79% | **C** |
| 60% – 69% | **D** |
| Below 60% | **F** |

## 🏆 High Score System

The program maintains high scores separately for each **category + difficulty** combination:

| Combination | Example |
| :--- | :--- |
| Easy + C Basics | 🎯 |
| Easy + Operators | ➕ |
| Easy + Loops | 🔄 |
| Medium + C Basics | 🎯 |
| Hard + Loops | 🔄 |

High scores are stored in `highscore.txt` and automatically loaded at startup.

> **Scoring Tie-breaker**: If two scores have the same percentage, the quiz with the **higher number of questions answered** is considered the better score.

## 🛠️ How to Compile

### Using GCC

```bash

```

### Run the Quiz

**macOS / Linux:**

```bash
./Quiz
```

**Windows:**

```bash
Quiz.exe
```
